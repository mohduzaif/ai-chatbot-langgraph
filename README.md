# LangGraph Streamlit Chatbot

A conversational AI chatbot built using **LangGraph** for backend workflow orchestration and **Streamlit** for the interactive frontend.

The project demonstrates how to build a simple conversational application with a state-based graph architecture while maintaining chat history during a conversation.

---

## 🚀 Features

- 🤖 Conversational AI chatbot
- 🔗 LangGraph-based backend workflow
- 🎨 Interactive Streamlit frontend
- 💬 Chat history management
- 🧠 State-based conversation handling
- 🔐 Environment variable support for API keys
- 🐍 Python-based implementation
- ⚡ Simple and lightweight architecture

---

## 🏗️ Project Architecture

The application is divided into two main components:

### Backend

The backend is responsible for:

- Managing the chatbot logic
- Building the LangGraph workflow
- Processing user messages
- Generating AI responses
- Managing conversation state

### Frontend

The frontend is developed using Streamlit and provides:

- Chat interface
- User input handling
- Display of conversation history
- Interactive chatbot experience
